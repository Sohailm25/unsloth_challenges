## FSDP2 + torch.compile Success!

### torch.compile Implementation

Successfully integrated torch.compile with FSDP2 + QLoRA training.

**Key Challenge**: HuggingFace Trainer explicitly blocks `torch.compile()` on quantized models when applied manually.

**Solution**: Use `torch_compile=True` via TrainingArguments instead of manually calling `torch.compile()`:
```python
training_args = SFTConfig(
    ...,
    torch_compile=True,
    torch_compile_mode="default",
)
```

This bypasses the manual compile check and lets Trainer handle compile timing correctly.
